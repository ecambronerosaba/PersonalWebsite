## What the site is for

A home base on the web: one place for who I am, what I've built, and what I'm writing. It is not a job-hunting portfolio, so the tone should be personal and low-pressure rather than a sales pitch.

- **Blog / writing:** launch with the site.
- **Photo gallery:** keep it as its own page.
- **Resume / LinkedIn:** link to [LinkedIn](https://www.linkedin.com/in/estebancambronero) (no hosted resume).

## Projects

### PuckPal

A community catalog of espresso shot profiles for the Fellow Espresso Series 1 (ES1). Home baristas browse, search, rate, and fork recipes, with pressure curves and extraction parameters for each shot. They can import profiles from brew.link and load them onto the machine with a QR code.

- **Stack:** Next.js 16, React 19, TypeScript, Supabase (Postgres), Clerk, Tailwind CSS, Vercel
- **Links:** [puckpal.io](https://puckpal.io) · [GitHub](https://github.com/ecambronerosaba/puckpal)

### Ergonaut keyboard

A wireless split keyboard that I 3D printed and programmed myself. The firmware is a custom ZMK config: nice!nano v2 controllers, nice!view displays on both halves, layered keymaps with tuned hold-tap behavior, and firmware binaries built automatically by GitHub Actions.

- **Stack:** ZMK, Zephyr RTOS, Devicetree, GitHub Actions
- **Links:** [GitHub](https://github.com/ecambronerosaba/zmk-config)
